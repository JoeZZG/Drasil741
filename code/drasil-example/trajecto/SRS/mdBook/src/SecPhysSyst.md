# Physical System Description {#Sec:PhysSyst}

The physical system of Trajecto, as shown in [Fig:trajectoPhysSys](./SecPhysSyst.md#Figure:trajectoPhysSys), includes the following elements:

PS1: A charged particle (the simulated particle)

PS2: The electric field in each field region (may differ between regions)

PS3: The magnetic field perpendicular to the x-y plane in each field region

PS4: The region grid of N equal-sized rectangular field regions

PS5: The detector line (horizontal or vertical) at a specified location
